# PowerComp — план (Claude, 2026-10-28; навыки synthcreator, test-driven-development)

**Запрос Романа (2026-10-28):** «Создай плагин динамический компрессор простой и понятный в стиле powerkick powerbass я не сильно разбираюсь как он должен работать так как не силен в этом но он мне нужен»; уточнения: «именно динамический», «который полосный». Устройство выбирает Claude.

## Решения
- **Многополосный компрессор, 3 полосы** (LOW / MID / HIGH): каждая сжимается отдельно, поэтому громкий бас не «душит» верх, а резкий верх — низ.
- **Разделение полос:** фильтры Линквица–Райли 4-го порядка (JUCE), низ дополнительно через фазовый фильтр второго разделителя → сумма полос без обработки не меняет АЧХ. Задержки нет (0 отсчётов).
- **Одна главная ручка на полосу — COMPRESS** (0–100 %): вместе опускает порог и повышает степень сжатия; у полос свои пороги (верх обычно тише). Рядом GAIN (±12 дБ), SOLO, BYPASS, индикатор сжатия.
- **AUTO GAIN** (включено): COMPRESS не делает звук тише — постоянная компенсация по кривой полосы (без «плавающей» громкости).
- **Общие:** SPEED (медленно — больше удара, быстро — плотнее; у низа время вдвое длиннее, чтобы бас не искажался), UPWARD (подтягивает тихие хвосты и детали, как OTT; ниже −72 дБ ничего не поднимает), MIX (параллельная компрессия, сухой сигнал — сумма тех же полос, без гребёнки), OUTPUT.
- **CROSSOVER:** LOW|MID 30–600 Гц (150), MID|HIGH 0,8–12 кГц (2,5); линии можно тянуть мышью на дисплее.
- **DIGITAL | ANALOGUE** (как во всей серии): ANALOGUE — тёплое мягкое насыщение низа и середины; переключение плавное, пресеты его не меняют.
- **ADVANCED:** AUTO GAIN, STEREO LINK.
- **Интерфейс:** язык серии (шапка, крупные главные ручки, панели, браузер пресетов, SAVE, ADVANCED); сверху дисплей — спектр входа и выхода, три зоны полос, перетаскиваемые разделители; справа OUTPUT с индикатором. Акцент — холодный голубой (у PowerKick белый, PowerBass оранжевый, PowerSynth зелёный).
- **Идентичность:** PowerComp, MyDarknessDays, `com.mydarknessdays.powercomp`, коды Mddy / Pwcp, AU-эффект (aufx), VST3 Fx|Dynamics; пресеты `.pcpreset`, `Documents/PowerComp/Presets`. Без отдельного приложения (у эффекта оно бесполезно).
- **Пресеты:** ~20 по задачам: Master, Drums, Bass, Synths, Vocals, Creative; громкость выровнена по эталонному техно-лупу (выход ≈ вход по RMS).

## К7. Умный режим LEARN (запрос Романа 2026-10-28: «ИИ-режим в стиле sonible… прослушивается дорожка и выставляются настройки, но при этом мануально тоже возможно и пресеты»)
- **Как работает:** кнопка LEARN в шапке → плагин слушает дорожку (копирует вход, звук не меняет), до 20 с звучащего материала (тишину пропускает); остановить можно раньше (не меньше 2 с). Затем в фоновом потоке анализ и подбор; результат сразу применяется к обычным ручкам.
- **Подбор настоящим движком:** записанный фрагмент прогоняется через тот же `CompEngine`; COMPRESS каждой полосы подбирается делением пополам так, чтобы громкие места (90-й процентиль подавления по 10-мс кадрам громкой части) сжимались на целевую величину профиля × AMOUNT. Затем OUTPUT выравнивает громкость (RMS выхода = RMS входа), чтобы сравнение было честным.
- **Профили:** AUTO (сила по крест-фактору материала, без угадывания жанра), DRUMS, BASS, SYNTH, PAD, BUS: целевое сжатие полос, SPEED (поправка по частоте атак), UPWARD, MIX, разделители (у BASS — по основному тону; верхний опускается, если наверху почти нет энергии).
- **AMOUNT** 0…100 % (50 % — норма профиля): после LEARN меняет силу без нового прослушивания (по сохранённому фрагменту).
- **Вручную и пресеты:** результат — обычные значения параметров: всё крутится, автоматизируется, сохраняется в проект и как свой пресет. A/B: BEFORE | LEARNED — точное возвращение настроек до LEARN и обратно. Профиль и AMOUNT — настройки экземпляра (сохраняются в проекте, пресеты их не меняют). DIGITAL | ANALOGUE и AUTO GAIN LEARN не трогает.
- **Честно:** у sonible — обученная нейросеть; здесь — детерминированный анализ и подбор с проверкой настоящим движком. Повторяемо, без сети.
- [x] Тесты (TDD) → движок подбора → процессор → интерфейс → выпуск, GitHub (2026-10-28, Claude). Поправка по ходу: AUTO не угадывает жанр (на настоящих лупах угадывание работало плохо), а подстраивается под крест-фактор; пустая полоса не сжимается; GAIN полос сохраняет тембр.
- Попутно: расширение пользовательских пресетов `.pspreset` (ошибка переноса из PowerSynth) → `.pcpreset`, старые файлы читаются.

## Риски
- Качество решает слух; числа не доказывают «мощь».
- Детектор по пикам на низких частотах с быстрым отпуском даёт искажения — поэтому у низа время длиннее; проверить на слух.
- Насыщение ANALOGUE без передискретизации: на очень высоком разделителе возможен слабый алиасинг середины.

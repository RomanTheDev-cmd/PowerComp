Добавлен второй, мгновенный детектор: начало удара может пройти выше полностью сжатого уровня не больше чем на 6 дБ (SLOW) … 2 дБ (FAST). Теперь худший рост пика бочки < 3 дБ.

**Проверки** (`powercomp_tests`, arm64): 72/72 — АЧХ ровная в нейтральном положении на 44,1/48/96 кГц при любых разделителях (±0,1 дБ), задержки нет, сжатие сужает разрыв громкое/тихое 20 → < 8 дБ в каждой полосе, полосы независимы, MIX 0 = сухой сигнал, SOLO/BYPASS/GAIN/OUTPUT, UPWARD не поднимает тишину и шум −90 дБ, AUTO GAIN держит громкость ±2 дБ, SLOW даёт больше панча, LINK, моно, ANALOGUE (гармоники только на громком), скачки 10 регуляторов без щелчков, размер блока и частота не влияют, крайние значения конечны, 20 пресетов ±1 дБ от входа и ниже 0 dBFS, нагрузка 0,9 % при 96 кГц. Мутационные проверки: без ограничения удара тест пиков падает (+32 дБ), без фазового фильтра — тест АЧХ (провал 9 дБ).

**Громкость пресетов:** OUTPUT рассчитан `powercomp_tests --calibrate` (эталонный техно-луп 130 BPM: бочка, бас, хэты, аккорд; выход = вход по RMS).
